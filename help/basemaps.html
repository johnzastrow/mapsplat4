Adding a basemap to your exported map

How to put a Protomaps PMTiles background (streets, places, water, land use) underneath your own layers. Covers MapSplat 0.45 and later. This guide is bundled with the plugin and also published at johnzastrow.github.io/mapsplat4/basemaps.html.

1. Choose a basemap mode

All basemap settings are on the Options tab under Basemap Overlay. Expand it and tick Enable basemap, then pick a Mode:

ModeUse it forNeeds the pmtiles tool?Needs internet to view?
Download & clip offline Protomaps basemaps (recommended). Cuts your area out of a Protomaps planet build and stores it in the export as data/basemap.pmtiles. YesFor the basemap: no. Labels and icons: see styles.
Stream from URL A PMTiles basemap you host on a server that allows cross-site access (CORS). The map reads it live. NoYes
XYZ raster Image tiles from an online provider (OpenStreetMap, Carto, imagery and others). NoYes
Protomaps' daily builds cannot be streamed. build.protomaps.com lets only Protomaps' own viewer read its files from a browser, so a map that streams a daily build shows no basemap, wherever it is hosted. The builds are meant to be downloaded and clipped (Protomaps discourages hotlinking them), which is what Download & clip offline does. MapSplat warns you if you try to stream one, and its Test button checks any URL for you.

2. Quick start: download and clip

  1. Install the pmtiles tool (section 4) and restart QGIS. This is a one-time step.
  2. On the Options tab, expand Basemap Overlay, tick Enable basemap and choose Mode: Download & clip offline. If MapSplat cannot find the tool, it shows a note with a download link.
  3. Leave Source: Remote URL and click Latest. MapSplat fills in the newest Protomaps daily build, for example https://build.protomaps.com/20261003.pmtiles.
  4. Pick a Basemap style, such as Protomaps Light. The built-in styles need no file.
  5. Set Max zoom (see sizes) and, if you like, an Export extent. The clip covers your selected layers, or that extent, plus a small margin.
  6. Export as usual. MapSplat downloads only your area, and your layers are drawn on top of it.

Clips are cached by source, area and max zoom, so exporting the same area again skips the download. To force a fresh download or free disk space, use Refresh basemap cache and Clear basemap cache under Advanced Options on the Inputs tab.

Protomaps keeps daily builds for only about a week (plus the latest build of each tile-schema patch version), so a dated URL soon returns HTTP 404. With Download & clip that only matters when you export, because your finished map keeps its own clipped copy: click Latest again before the next export.

3. Streaming a PMTiles file you host

Streaming suits a basemap you publish once and share across many maps, for example a regional clip on your own server or cloud bucket. The map then reads only the tiles it needs, live.

  1. Make a clip (see section 5) or obtain a .pmtiles file.
  2. Upload it to a host that supports HTTP range requests and send these CORS headers for it: 
    Access-Control-Allow-Origin: *
Access-Control-Allow-Headers: Range
Access-Control-Expose-Headers: Content-Range, Content-Length, ETag
    Object stores such as Amazon S3, Cloudflare R2 and Google Cloud Storage support this through their CORS settings; see the Protomaps cloud storage guide.
  3. Choose Mode: Stream from URL, paste the file's URL and click Test. It reports whether browsers on other sites may read the file.
  4. Pick a Basemap style and export.

4. Installing the pmtiles tool

The tool is a single program from the go-pmtiles releases page. MapSplat never downloads or installs it for you.

  1. Download the archive for your system from the releases page: Windows_x86_64, Darwin_arm64 (Apple silicon), Darwin_x86_64 (Intel Mac) or Linux_x86_64; ARM builds exist for Windows and Linux too.
  2. Unpack it. It contains one program: pmtiles (pmtiles.exe on Windows).
  3. Put that program in a folder on your PATH, for example ~/.local/bin or /usr/local/bin on macOS and Linux. On Windows, add its folder in Settings > System > About > Advanced system settings > Environment Variables > Path.
  4. Check it from a new terminal: pmtiles version
  5. Restart QGIS so it sees the updated PATH.
On macOS, if the system blocks the program the first time, allow it under System Settings > Privacy & Security, or install it with Homebrew if you use it.

5. Clip once, reuse many times

If you export the same area often, or want to control the download yourself, clip the basemap once and point MapSplat at the result:

  1. Select your layers (or set an Export extent) and a Max zoom, and choose Download & clip offline.
  2. Click Copy extract command. MapSplat copies the exact command it would run for that area, for example: 
    pmtiles extract https://build.protomaps.com/20261003.pmtiles basemap.pmtiles --bbox=-70.32,43.62,-70.18,43.72 --maxzoom=14
  3. Paste it into a terminal and run it.
  4. In MapSplat choose Source: Local file and select the new basemap.pmtiles.

To work out a bounding box by hand, bboxfinder.com gives west,south,east,north coordinates, and pmtiles.io previews any .pmtiles file in your browser. The tool can also clip to a polygon with --region=area.geojson; see the pmtiles CLI documentation.

6. Basemap styles

A style decides how the basemap looks. MapSplat ships five, generated from Protomaps' official @protomaps/basemaps package:

StyleGood for
Protomaps LightGeneral use; the default.
Protomaps DarkBright data layers, dark interfaces.
Protomaps WhiteMinimal background so your data stands out.
Protomaps GrayscaleNeutral background for coloured thematic maps.
Protomaps BlackHigh-contrast dark background.

To use a different look, choose Custom style.json... and browse to a Protomaps-compatible MapLibre style. The Get style JSON button on maps.protomaps.com produces one for any flavour and language. MapSplat points the style's vector source at your chosen basemap automatically.

Labels and icons come from the internet. The built-in styles load their fonts and icons from protomaps.github.io when the map is viewed. With Download & clip the basemap's shapes work offline, but place names and icons need a connection. For a fully offline map, use a custom style whose glyphs and sprite URLs point at copies on your own server; Protomaps publishes them in the basemaps-assets repository.

7. Max zoom and download size

Each extra zoom level shows more detail and roughly multiplies the clip size. Protomaps builds contain detail up to zoom 15; above that the map simply magnifies. Clip sizes measured from a 2026 planet build (the whole planet is about 138 GB):

AreaMax zoomBasemap clip
A city (Portland, Maine)14about 2.3 MB
A county (Cumberland County, Maine)13about 6 MB
A state (Maine)10about 11 MB
A state (Maine)12about 37 MB

To see the size before downloading, add --dry-run to a copied extract command.

8. Viewing and hosting the map

PMTiles are read with HTTP range requests, which browsers do not make for files opened directly from disk. To view an export on your own computer, run the bundled server in the export folder:

python serve.py

To publish, upload the whole export folder to any static web host that supports range requests, for example GitHub Pages, Netlify, Caddy or nginx. The export's README.txt lists the details, including the CORS headers needed if the tiles are on a different host.

9. Troubleshooting

What you seeCause and fix
Test reports HTTP 404 for the basemap URL That daily build has expired. Click Latest.
Test says the server "does not let browsers on other sites read it" The file cannot be streamed. For a Protomaps daily build, switch to Download & clip offline; for your own file, enable CORS on its host (section 3).
The note "The pmtiles tool was not found on your PATH" Install it (section 4) and restart QGIS. Without it, only Stream from URL (a file you host) or XYZ raster can add a basemap.
Your layers show but the basemap area is blank Open the map through serve.py or a web server, not by double-clicking index.html. A streamed map shows no basemap if its source does not allow CORS, which includes every Protomaps daily build; use Download & clip offline.
The basemap shows but place names or icons are missing The viewer cannot reach protomaps.github.io; see the note in section 6.
A custom style draws nothing The style must be Protomaps-compatible (for the Protomaps tile schema). Styles for other tile schemas do not match its layer names.
The export is slow Lower Max zoom, narrow the Export extent, or clip once and reuse a local file.
