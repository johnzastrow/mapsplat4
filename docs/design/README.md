# Design & Planning Archive

Historical planning, design, and analysis notes kept for reference. These are **not** user
documentation and may be out of date — for current information see the top-level docs (the
[User Guide](../USER_GUIDE.md), [Features](../FEATURES.md), etc.) and the active
[roadmap/backlog](../FEATURE_BACKLOG.md).

| File | What it is |
|---|---|
| `IMPLEMENTATION_PLAN.md` | Original phased implementation plan |
| `REQUIREMENTS.md` | Early requirements capture |
| `VIABILITY.md` | Feasibility / viability analysis |
| `PLAN.md` | General planning notes |
| `TODO.md` | Historical task list (superseded by the backlog) |
| `BACKLOG_ANALYSIS.md` / `.pdf` | Backlog analysis write-up |
| `DOCK_UX_REDESIGN.md` | Dock UX redesign notes |
| `MARKER_APPROACH.md` | Notes on the SVG marker / sprite approach |
| `FIX_NRD_WEATHER.md` | Notes from a specific fix investigation |
| `background.md` | Background / context notes |
